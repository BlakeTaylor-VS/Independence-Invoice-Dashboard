# Late Fee Breakdown Patch — Independence Invoice Dashboard ## What this fixes Tiers 3 (30-day), 4 (45-day), and 5 (60-day) currently show a generic paragraph explaining the late fee POLICY, but never compute the actual dollar amount per invoice. This patch adds a real per-invoice calculation and a breakdown column in the invoice table for any invoice 30+ days overdue. ## Fee logic (as confirmed) - Day 31: one-time 3% applied to the open balance. - Every 7 days after that (day 38, 45, 52...): add $50 to the running balance, THEN apply 3% on top of that new balance (compounding, not flat). - Before day 31: no fees, balance = open amount. ## Step 1 — Add this function in index.html Paste this anywhere above `buildAgencyEmail` (e.g., right above the `function buildAgencyEmail` line): ```javascript function calcLateFee(openAmount, days) { if (days < 31) return { fees: 0, total: openAmount, cycles: 0 }; let balance = openAmount * 1.03; // immediate 3% at day 31 const cycles = Math.floor((days - 31) / 7); // number of $50+3% weekly cycles since day 31 for (let i = 0; i < cycles; i++) { balance = (balance + 50) * 1.03; } return { fees: balance - openAmount, total: balance, cycles }; } ``` ## Step 2 — Replace the `rows` and `invoiceTable` block in `buildAgencyEmail` Find this existing block (around line 631-642): ```javascript const rows = invoices.map(r => { const days = daysOverdue(r.due); const statusLabel = days > 0 ? `${days} days overdue` : `Due in ${Math.abs(days)} days`; return `Invoice #${r.num}Due: ${r.due}Billed: ${fmt(r.amount)}Open: ${fmt(r.open)}${statusLabel}`; }).join(''); const invoiceTable = `${rows}
